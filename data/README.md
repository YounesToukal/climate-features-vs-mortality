# Data

The files of the Zindi Climate Risk and Health Prediction Challenge, unchanged. Zindi releases them under the [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) licence, which also applies to this folder.

| File | Contents |
| --- | --- |
| `Train.csv` | 3,146 deaths with the label `is_climate_sensitive` |
| `Test.csv` | 1,030 deaths without the label |
| `climate_features.csv` | Rainfall (CHIRPS), temperature (ERA5-Land), vegetation (MODIS) and terrain (SRTM) variables for every death, joined on `ID` |
| `SampleSubmission.csv` | The submission format |
| `data_dictionary.csv` | Descriptions of the `Train.csv` and `Test.csv` columns |
| `downloaded_climate_features_data_dictionary.csv` | Descriptions, units and sources of the `climate_features.csv` columns |
